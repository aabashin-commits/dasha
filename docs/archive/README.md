# Архив

Здесь лежит документ, описывающий **предыдущую** архитектуру проекта — ту,
где страницы генерировались скриптом из JSON-файлов.

От сборки отказались осознанно: она требовала запускать команду после
каждой правки, а это оказалось дороже, чем ручное дублирование шапки
и подвала по файлам.

Документ сохранён как справка: в нём подробно расписаны SEO-требования,
схемы микроразметки, сценарии проверки формы и требования к доступности.
Всё это по-прежнему верно и соблюдается в текущей версии — не относится
только то, что касается сборки, валидатора и структуры `content/`.

Рабочий код той версии остался в истории git, коммит `f048c77`.
