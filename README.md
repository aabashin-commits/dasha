# Keyframe

Сайт видеопродакшн-студии. Обычные HTML-файлы: что лежит в папке — то и открывается в браузере. Сборки нет.

---

## Посмотреть сайт

Двойной клик по файлу **«Посмотреть сайт.command»** в корне. Откроется браузер.

Зачем нужен запускатор: ссылки на разделы ведут на папку (`works/`, а не `works/index.html`). Так правильно и для хостинга, и для адресов в поиске, но при открытии файла напрямую с диска браузер по такой ссылке показывает список файлов вместо страницы. Скрипт поднимает маленький локальный сервер и снимает вопрос. Ничего устанавливать не нужно — используется Python, который уже есть в macOS.

## Пути внутри проекта — только относительные

Все ссылки на стили, скрипты, картинки и страницы записаны относительно текущего файла: `./assets/style.css` на главной, `../../assets/style.css` на странице кейса.

Это не придирка, а условие работоспособности. Абсолютный путь вида `/assets/style.css` ищет файл в корне домена. Если сайт лежит в подкаталоге — например, на GitHub Pages по адресу `логин.github.io/dasha/` — такой путь уходит мимо, и страница открывается без стилей вообще.

**Добавляете ссылку или картинку — считайте уровни вложенности.** С главной это `./`, из `works/` — `../`, из `works/название-кейса/` — `../../`.

Абсолютными остаются только полные адреса с доменом: `canonical`, `og:url` и содержимое `sitemap.xml`. Там это обязательно по стандарту.

## Что где лежит

```
index.html            главная
services/             направления: список и по странице на каждое
works/                портфолио: список и по странице на каждый кейс
journal/              журнал: список и по странице на статью
about/                о студии
contacts/             контакты
privacy/              политика обработки данных
404.html              страница «не найдено»
styleguide/           служебная: вся дизайн-система на одной странице

assets/style.css      все стили, один файл
assets/script.js      все скрипты, один файл
media/                изображения
fonts/                шрифты
api/                  обработчик формы заявок (PHP)
```

## Как править

**Тексты и структуру** — прямо в HTML-файле нужной страницы. Открываете, меняете, сохраняете, обновляете вкладку.

**Цвета, размеры, отступы** — в начале `assets/style.css`, блок `:root`. Там переменные вида `--lime`, `--bg`, `--sp-4`. Меняете значение в одном месте — меняется на всём сайте.

**Поведение** — `assets/script.js`. Файл разбит на блоки с заголовками: спайн, кадры героя, меню, фильтр, лайтбокс, форма.

Подробности с примерами — [docs/how-to-edit.md](docs/how-to-edit.md).

## Важно помнить

Сборки больше нет, поэтому **повторяющиеся куски придётся править в каждом файле**. Шапка, подвал и форма заявки продублированы на всех 22 страницах. Если меняете телефон или пункт меню — меняйте везде.

Быстрый способ найти все вхождения:

```
grep -rl "старый текст" --include=*.html .
```

Это осознанный размен: раньше такие правки делались в одном месте, но требовали шага сборки. Прежняя версия с генератором сохранена в истории git — коммит `f048c77`.

## Выложить на хостинг

Залить всё содержимое папки на сервер. Подробности, настройка формы и обязательные проверки — [docs/deploy.md](docs/deploy.md).

Перед публикацией нужно:

1. Заменить домен-заглушку `keyframe.example` в `sitemap.xml` и в тегах `canonical` и `og:url` на всех страницах.
2. Заполнить `api/config.php` — токен Telegram-бота и доступы к почте. Образец: `api/config.sample.php`.
3. Заменить реквизиты юрлица в `privacy/index.html` и показать текст юристу.
4. Вписать ID Яндекс.Метрики в атрибут `data-metrika` тега `<body>` и переключить `data-analytics` в `on`.
5. Заменить изображения-заглушки в `media/` на настоящие.
